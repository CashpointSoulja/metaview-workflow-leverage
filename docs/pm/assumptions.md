# Assumptions

| A2 | Implementation facts include ATS, video tool, SSO, consent and seat count | Medium: these are the public integration and security topics | review 10 real handoffs |
| A3 | Those facts live mostly in free text | Low | sample sources per deal (H1) |
| A4 | A CS owner roster exists and can own gaps | Medium | org chart |
| A5 | Timing data can be captured without heavy process | Low | pilot a lightweight timer for 2 weeks |
| A6 | A thin checker is cheaper to maintain than a new platform | Medium | compare against vendor quotes and CRM config cost |
| A7 | 45 days is a reasonable staleness window | Low: chosen for the demo | check typical sales cycle length |

If A1 or A3 is wrong, the handoff is the wrong first workflow and the ranking should be re-run with real inputs.
