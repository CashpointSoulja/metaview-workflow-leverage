# V2 roadmap

Ordered by what I'd need to learn first.

1. **Discovery with real handoffs.** Run the interview guide, sample 10 to 20 handoffs, replace the synthetic ranking inputs.
2. **Read-only CRM import.** Pull order forms and notes read-only, keep the same validation and atomic import.
3. **Shared team workspace.** One Durable Object per team, roles for AE, CS owner and approver.
4. **Model as candidate generator.** Let a model propose facts, still accepted only with an exact quote and still abstaining on conflict. Measure against the eval set before switching on.
5. **Checkpoint reminders.** Draft (not send) reminders to the owner when a checkpoint is due.
6. **Second workflow.** Re-run the ranking and apply the same playbook to the next candidate (likely renewal-risk brief).
